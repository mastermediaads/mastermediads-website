# Master Media Ads Website (موقع وكالة ماستر ميديا للإعلانات)

موقع ويب متكامل وعصري لوكالة التسويق الرقمي والإعلانات الممولة **Master Media Ads**.

## المميزات:
- تصميم عصري يدعم اللغة العربية (RTL) بشكل كامل مع خطوط عربية فاخرة (Cairo & Tajawal).
- متجاوب بالكامل مع كافة مقاسات الشاشات (الهواتف الذكية، الأجهزة اللوحية، والشاشات الكبيرة).
- **حاسبة العائد الاستثماري التفاعلية (ROI Calculator)**: تتيح للعملاء تقدير نتائج حملاتهم الإعلانية فوراً.
- معرض أعمال مصفى حسب الفئة (حملات رقمية، فيديو UGC، هويات بصرية).
- نموذج تواصل تفاعلي مرتبط بمحادثة واتساب الفورية لزيادة التحويلات والطلبات.
- متوافق مع الاستضافة على **GitHub Pages**، **Netlify**، أو **Vercel**.

## طريقة تشغيل الموقع محلياً:
- افتح ملف `index.html` في أي متصفح لديك (مثل Google Chrome أو Microsoft Edge).

## طريقة رفع الموقع على GitHub Pages ليصبح متاحاً للجميع على الإنترنت:
1. اذهب إلى مستودعك على GitHub: [https://github.com/mastermediaads/mastermediads-website](https://github.com/mastermediaads/mastermediads-website)
2. اضغط على **"Add file"** ثم **"Upload files"**.
3. اسحب الملفات التالية وضعها في صفحة الرفع:
   - `index.html`
   - `404.html`
   - مجلد `css` (يحتوي على `custom.css`)
   - مجلد `js` (يحتوي على `main.js`)
4. اضغط **Commit changes**.
5. اذهب إلى إعدادات المستودع **Settings** > **Pages** > في خيار **Source** اختر **Deploy from a branch** ثم اختر الفرع `main` واضغط **Save**.
6. سيصبح موقعك متاحاً على الرابط:
   `https://mastermediaads.github.io/mastermediads-website/`
